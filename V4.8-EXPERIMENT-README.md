# Student Progress Tracker V4.8 — Individual Workspace Experiment

This folder is an isolated experiment based on the recovered V4.7 project. It preserves the teacher dashboard shell and replaces the individual student workspace body with the original single-student report workflow.

## Included behavior

The individual student workspace includes the original-style weekly report, 4-day and 6-day teaching routines, direct table-row entry, score fields with visual progress bars, checklist and checklist-progress views, assessment history, daily learning records, teacher notes, guardian summary, and print support. The table is intentionally wide and is contained by a touch-friendly horizontal scroll wrapper on narrow screens.

The student header uses a stateful room lifecycle. A student without an active room shows `রুম তৈরি করুন`; an active room shows its code, copy control, and room termination control; after termination the header returns to the create state. Guest/Test Mode uses isolated localStorage data and cannot write to Firebase.

## Validation completed

The modified JavaScript modules pass Node syntax checks. A local browser test confirmed that Bengali direct entry remains in place without page navigation or input focus loss, that the report status updates to saved, that the room create/terminate state cycle works in Guest/Test Mode, and that the weekly sheet uses a local horizontal scroller without document-level horizontal overflow at desktop width. Both 4-day and 6-day routines were checked.

## Local test

From this directory, serve the folder with any static HTTP server, for example:

```bash
python3 -m http.server 4174
```

Then open `http://127.0.0.1:4174/` and choose Guest/Test Mode. This experiment should be reviewed before copying its files into the production GitHub repository.

## Important boundary

The recovered V4.7 project and production Firebase data were not modified by the final V4.8.2 fixes. Do not upload this experiment over production until the owner approves the visual and mobile test results.
